# Viona Toyota Rantauprapat

A modern web application and catalog for Toyota Viona Rantauprapat, built with Next.js and TypeScript, featuring vehicle listings, pricing details, galleries, and an AI-powered car recommendation feature.

## Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Live Demo:** [vionatoyotarantauprapat.vercel.app](https://vionatoyotarantauprapat.vercel.app/)
